# План обучения: (джун-мидл) → системный аналитик (мидл) / фулстек анализ (+ элементы архитектуры)

Особенности аудитории: слабая теоретическая база, небольшой кругозор.
Цель: переход в системный/фулстек анализ и **выход на уровень мидл**.

## Формат и структура

- **Модуль → Тема → Урок**; каждый урок — онлайн-занятие **ровно 90 минут (не более)**.
- 59 уроков × 90 мин = 5310 минут суммарно.
- Каждая тема = 1–3 урока; каждый модуль завершается аттестацией (демо-задача + ревью).
- Цикл на каждом уроке: теория → разбор практического примера → практика → ревью → повторение (spaced repetition).
- После Модуля 3 (урок 33) — **точка готовности пробоваться на позицию мидла**; модули 4–8 — укрепление позиции.
- Модули 6–7 можно вести параллельно с модулями 3–5 и с рабочими задачами.
